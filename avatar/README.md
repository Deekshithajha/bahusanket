# Signing avatar viewer

`index.html` plays pose sequences on a 3D VRM avatar (three.js + three-vrm), or as a stick figure, with a speed control.
It expects `clips.json` (pose frames from iSign clips, kept out of git as data) and `avatar.b64.txt` (the avatar `.vrm`, base64) next to it.
Avatar: pixiv VRM1_Constraint_Twist_Sample, VRM Public License 1.0.
